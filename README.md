# Tienda online de informática y gaming para Córdoba (nombre provisional)

Proyecto de la asignatura de Proyecto del ciclo de Desarrollo de Aplicaciones Web (DAW), Campus Córdoba.

## Problema

Los comercios locales de informática y gaming de Córdoba suelen depender de la tienda física y de marketplaces ajenos. No tienen un canal de venta propio ni una comunidad de clientes. Este proyecto propone una tienda online con foro moderado.

## Funcionalidades previstas

- Catálogo de ordenadores, componentes y videojuegos, con carrito y pedidos.
- Cuentas de cliente.
- Foro accesible solo para usuarios registrados, con normas de conducta, botón de reportar mensaje y baneo.
- Panel de administración de productos, stock, pedidos, reportes y bans.
- Páginas legales: aviso legal, privacidad, cookies, condiciones de compra y devoluciones.
